Privacy Policy

Calendar Reader (local) is a personal tool used only by its owner. Last updated: November 13, 2026.

What it accesses

With the owner's permission, it reads the owner's Google Calendar list and events (read-only scope calendar.readonly). It cannot create, change or delete events.

How the data is used

Calendar data is read only when the owner asks for it, on the owner's own computer, for the owner's personal use. It is not sold, not used for advertising, and not shared with other people.

Storage

The sign-in token is stored only on the owner's computer. The tool keeps no server and no database of calendar data.

Removing access

Access can be removed at any time from the Google Account page Third-party apps with account access.

Contact

Questions can be left as an issue on this repository.
